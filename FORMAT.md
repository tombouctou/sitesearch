# Указатель: договор

Указатель — один статический файл JSON. Его пишет сборщик, читает движок, и
больше между ними ничего не происходит: движок не знает, из чего собран
указатель, а сборщик — как устроена выдача. Всё, что здесь описано, — это и
есть граница.

```json
{
  "pages": [
    {
      "url": "/links/math/",
      "title": "Математика",
      "also": "Math",
      "section": "Ссылки",
      "order": 1,
      "blocks": [
        { "text": "Абзац как он есть, голым текстом.", "anchor": "p7", "section": "Производные" },
        "Абзац без якоря и без заголовка над ним."
      ]
    }
  ],
  "shards": [
    { "url": "/b/mctb2/search-index.json", "section": "Книга", "order": 6, "defer": true }
  ]
}
```

## Страница

| поле      | обязательно | что это                                                              |
|-----------|-------------|----------------------------------------------------------------------|
| `url`     | да          | адрес, по которому её отдаёт сайт                                    |
| `title`   | да          | имя, которое стоит в строке над находкой                             |
| `also`    | нет         | второе имя, которое ищется наравне с первым, но не показывается      |
| `section` | нет         | раздел сайта; источник может назвать его за всю пачку сразу          |
| `order`   | нет         | порядок в выдаче; страницы с одним `order` идут как перечислены      |
| `blocks`  | да          | куски текста на ней                                                  |

Страница — сама по себе находка: если запрос подошёл к её имени, она попадёт в
выдачу, даже когда ни один абзац не подошёл. Иначе слово, живущее только в
заголовке главы, не найдётся вовсе.

`also` нужен там, где короткое имя и полное — разные строки: оглавление
сокращает «3. Концентрация: второе упражнение» до «3. Концентрация», а искать
надо по обоим.

## Блок

Абзац, пункт списка, строка таблицы, строфа — что сборщик счёл единицей текста.

| поле      | обязательно | что это                                                          |
|-----------|-------------|-------------------------------------------------------------------|
| `text`    | да          | голый текст, без разметки и без сущностей                         |
| `anchor`  | нет         | якорь на странице, куда ведёт ссылка (без «#»)                    |
| `section` | нет         | заголовок раздела над этим куском; ищется вместе с текстом        |

Блок, у которого нет ни якоря, ни заголовка, пишется просто строкой:
`"Абзац как он есть."` Это то же самое, что `{"text": "Абзац как он есть."}`, —
короче в файле и проще в шаблоне Liquid, где каждая скобка стоит труда.

**Текст должен быть голым.** Ни `<b>`, ни `**`, ни `&amp;`: то, что попало в
`text`, показывается читателю как есть и по нему же ищут. Снять разметку —
работа сборщика, у которого страница в руках целиком; движок, взявшийся её
снимать, тем самым узнаёт, из чего собран указатель, и договора больше нет.

## Соседние указатели

`shards` — другие указатели, которые надо искать вместе с этим. Каждый описан
теми же полями, что источник в `mount()`: `url`, и по желанию `section`,
`order`, `defer`, `precompressed`.

Так состав сайта задаёт сборщик, а не переписывает каждая страница поиска: она
называет один указатель, остальное приезжает следом.

`defer` откладывает загрузку до первого запроса — мегабайт книги незачем везти
тому, кто зашёл на страницу мимоходом.

`precompressed` говорит, что рядом лежит `<url>.br`: движок попросит сначала
его. Хостинг обязан отдавать такой файл с `content-encoding: br`; если он
перестанет, движок вернётся к обычному файлу сам. Там, где сжатую копию
положить некуда, пометки быть не должно — иначе каждый указатель стоит лишнего
404.

## Чего здесь нет

Ни обратного индекса, ни позиций, ни весов. Указатель — это текст сайта,
разложенный по страницам, и совпадения ищутся по нему целиком, при каждом
нажатии клавиши. Пока текст сайта укладывается в несколько сотен килобайт в
brotli, это дёшево, и один файл выигрывает у любой разбивки: он приезжает один
раз, а дальше поиск ничего не грузит вовсе.
